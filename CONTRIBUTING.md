# Aether'a Katkıda Bulunma

Katkılar memnuniyetle kabul edilir.

## Geliştirme

Aether Python 3.10+, GTK4, Libadwaita ve çalışan bir Ollama sunucusu kullanır.

```bash
git clone https://github.com/MOzcelik14/Aether.git
cd Aether
python3 -m compileall -q .
python3 aether.py
```

## Pull Request

- Değişiklikleri küçük ve anlaşılır commitlere ayırın.
- Kullanıcı arayüzü değişikliklerinde ekran görüntüsü ekleyin.
- Yeni davranışlarda hata durumlarını ve Ollama bağlantısının kapalı olmasını test edin.
- `python3 -m compileall -q .` ve `bash -n install.sh` kontrollerini çalıştırın.
